Entry for the [One-Line Laugh-Off](https://make.fun/bounty/u-zkhiel-one-line-laugh-off-714618ae) bounty on make.fun: exactly one funny line, written by `main.py` to `$MAKEFUN_OUTPUT_DIR/entry.txt`.

## The line

> My phone's screen-time report judged me so hard it filed for a restraining order.

## Run

```sh
MAKEFUN_OUTPUT_DIR=output python3 main.py
```

Deterministic, standard library only, no network. The program self-checks the kit gate (UTF-8 text, 1–200 characters, a single line, not only whitespace) before writing.
